PpTeX syntax

You write only what is on the slide and how the pieces sit next to each other. Colour, size and spacing are the renderer's business.

1. Slides

# First slide
Body
---
# Second slide
Body

2. Text levels

^ 01
# Section Title
## Subtitle
Body text sits beside the title block.
^caption (small line above the title)
#title
##subtitle
(none)body text
1.numbered list

Caption or no caption, the title keeps exactly the same place and size. Adjacent 1. 2. 3. lines are gathered into one list.

3. Images

!photo.jpg

!a.jpg | First
!b.jpg | Second
!c.jpg | Third

A bare ! leaves an empty image slot. Drop a picture onto that slot in the preview and the filename is written into the source for you.

!

Images are cropped to fill their slot. Double-click one in the preview to set zoom and focal point; the values are recorded after ~.

!photo.jpg ~ 1.4 38 22 | Caption

You will rarely type this by hand. The order is ~ zoom focalX focalY.

The Images bar under the toolbar holds every picture the deck knows about. + Add takes them from your computer, dropping them anywhere on the window works too, and clicking a chip writes !filename in at the caret.

4. Layout

Layout is decided by line breaks.

C            →  A → B → C   (across)

A

C            →  A ↓ B ↓ C   (down)

Text, images and groups all follow the same rule.

Indentation is not syntax. It is only there to make the source easier to read.

6. Breaking a line inside one block

A \ at the end of a line continues the same text element on the next line. It works in @footer too.

Objects on the desk exist separately. \
Cables become tangled, and the experience becomes fragmented.
line breakplace across
blank lineplace down
\ + line breakbreak inside one block

7. Slide modifiers

@bg !backdrop.jpg ~ 1.6 40 30
@footer Your name \
2026

! still means the same thing. !backdrop.jpg is placed as an element; @bg !backdrop.jpg becomes the slide background. ~ works here too — double-click the background where no element covers it to set its zoom and focal point.

PpTeX has no low-level style attributes such as @color @size @margin @align.

Files

Open a .pptex / .txt file with Open and from then on you are editing that file directly. Edits are saved automatically a moment later, and ⌘/Ctrl+S saves at once. Dropping a text file onto the window opens it too. The chip beside the logo says which it is — Saved for a file on disk, Browser draft for work kept in this browser under no name.

A browser draft is not lost when you close the tab, but it lives in this browser only — Save gives it a real file. Editing files in place works in Chromium browsers, and may be blocked when the page is opened over file:// — serving it from a local server is safer.

Export

Export at the top right offers PowerPoint (.pptx) and PDF (.pdf).

For PDF, use the print dialog with Destination: Save as PDF and Margins: None. Pages are 16:9 (1280×720), and background colours print whatever the background-graphics setting says.

PPTX carries the geometry measured in the preview straight across — text becomes text boxes, photos become pictures — so you can keep editing in PowerPoint. If the Freesentation font is not installed, only the letterforms fall back to another font.
