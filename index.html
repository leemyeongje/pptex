PpTex 문법

무엇이 슬라이드에 있고 요소들이 공간적으로 어떤 관계인지만 적습니다. 색·크기·여백 같은 스타일은 렌더러가 정합니다.

1. 슬라이드

# 첫 슬라이드
내용
---
# 둘째 슬라이드
내용

2. 글의 계층

^ 01
# Section Title
## Subtitle
Body text sits beside the title block.
^캡션 (제목 위 작은 글씨)
#제목
##부제
(없음)본문
1.번호 목록

따옴표는 문법이 아닙니다. 그냥 글자입니다.

# "Quotation marks are just text."
## Attribution

캡션이 있든 없든 제목의 위치와 크기는 똑같습니다. 번호 목록은 붙여 쓴 1. 2. 3. 줄이 한 덩어리로 묶입니다.

3. 이미지

!photo.jpg

!a.jpg | First
!b.jpg | Second
!c.jpg | Third

! 만 쓰면 빈 이미지 자리가 됩니다. 미리보기의 그 자리에 이미지를 끌어다 놓으면 파일명이 소스에 채워집니다.

!

이미지는 자리에 꽉 차게 잘립니다. 미리보기의 이미지를 더블클릭하면 확대·초점을 맞출 수 있고, 그 값이 ~ 뒤에 기록됩니다.

!photo.jpg ~ 1.4 38 22 | Caption

직접 칠 일은 거의 없습니다. ~ 확대 초점X 초점Y 순서입니다.

4. 배치

배치는 줄바꿈이 정합니다.

A
B
C            →  A → B → C   (가로)

A

B

C            →  A ↓ B ↓ C   (세로)

글·이미지·그룹 모두 같은 규칙을 따릅니다.

5. 그룹

[ ] 로 여러 요소를 하나의 요소로 묶습니다.

A
[
    B

    C
]
D            →  A → [B ↓ C] → D

그룹 안에서도 규칙은 똑같습니다.

[
    A
    B
]

[
    C
    D
]            →  [A → B]
                     ↓
                  [C → D]

들여쓰기는 문법이 아닙니다. 읽기 편하라고 쓰는 것뿐입니다.

6. 글 안에서 줄바꿈

줄 끝의 \ 는 같은 글 요소를 다음 줄로 잇습니다. @footer 에서도 같습니다.

Objects on the desk exist separately. \
Cables become tangled, and the experience becomes fragmented.
줄바꿈가로 배치
빈 줄세로 배치
\ + 줄바꿈글 안에서 줄바꿈

7. 슬라이드 수식어

@bg !backdrop.jpg
@footer Your name \
2026

! 의 뜻은 그대로입니다. !backdrop.jpg 는 요소로 놓이고, @bg !backdrop.jpg 는 슬라이드 배경이 됩니다.

PpTex 에는 @color @size @margin @align 같은 저수준 스타일 속성이 없습니다.

파일

열기로 .pptex / .txt 파일을 열면 그때부터 그 파일을 직접 고칩니다. 편집하면 잠시 뒤 자동 저장되고, ⌘/Ctrl+S 로 즉시 저장할 수 있습니다. 텍스트 파일을 창에 끌어다 놓아도 열립니다.

파일을 열지 않은 상태에서는 브라우저에 임시 저장만 됩니다. 파일 직접 편집은 Chrome 계열에서 동작하며, file:// 로 열면 막힐 수 있으니 로컬 서버로 여는 편이 안전합니다.

편집

⌘/Ctrl + S저장
⌘/Ctrl + Enter새 슬라이드

이미지 드래그&드롭미리보기의 그 자리에 채워 넣기
